# Security policy

This is pre-release wallet software. Do not use candidate or development
profiles for production funds.

Report vulnerabilities privately through the contact channel published at
https://www.unftchain.com/. Do not include mnemonics, private keys, xprvs or
funded raw transactions in a report.

The backend boundary accepts only public chain data and signed transactions.
Seed material, private keys and account xprvs must remain on the user device.
